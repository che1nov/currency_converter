# Конвертер Валют

## Описание

Сервис для конвертации валют по заданным курсам. Сервис позволяет конвертировать сумму из одной валюты в другую и просматривать историю всех конвертаций.


## Описание API

POST /convert

Конвертирует сумму из одной валюты в другую.

Request Body:
```
{
  "amount": 100,
  "from_currency": "USD",
  "to_currency": "EUR"
}
```
